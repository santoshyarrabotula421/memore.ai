AI-Powered Assistant Web App (React + Vite + Tailwind)

Robot Powers Hub is an intelligent assistant web application inspired by Memora.ai, built using React (JavaScript), Vite, and Tailwind CSS.
The project includes an enhanced login experience, multiple feature pages, and a visually engaging UI demonstrating how an AI assistant can manage reminders, tasks, and more.

📌 Features
🔹 AI Reminder Demo

WhatsApp-style Reminder Interaction

User sends: “Hello, remind me to call mom at 4pm”

AI responds: “Reminder set”

Contact name shown as Memore.ai

🔹 Pages Included

Home (Index) – Simple landing page

Login Page – Enhanced UI with background image

Superpowers Section – Multiple feature pages (e.g., Calendars, Lists, Voice, Unlimited Reminders)

Pricing Page

404 Page (fallback)

🔹 Tech Stack

⚛ React (JavaScript + JSX)
